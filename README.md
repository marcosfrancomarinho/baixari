# 📥 Baixari

Frontend desenvolvido em **React + TypeScript** para consumir o backend do projeto Baixari e oferecer uma interface para operações de download.

## 🛠️ Tecnologias

- React 19
- TypeScript
- Vite
- Tailwind CSS

## ▶️ Desenvolvimento

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## 📦 Estrutura

O projeto concentra a interface web, enquanto as regras de preparação e entrega dos arquivos ficam no repositório `baixari-backend`.

## 🎯 Objetivo

Separar a experiência de uso no frontend das responsabilidades de manipulação e disponibilização de arquivos no backend.
